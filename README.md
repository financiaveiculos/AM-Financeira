# AM Financeira — Site Institucional

## Arquivos
- `index.html` — Página principal
- `cliente.html` — Para o caminhoneiro
- `lojista.html` — Para o lojista parceiro
- `lojista-hero.png` — Foto hero da página lojista
- `lojista-negociacao.png` — Foto da seção visual split
- `LogoAMFinanceira.png` — Logo (adicionar antes do deploy)
- `itau.png`, `bradesco.png`, `santander.png`, `bv.png`, `daycoval.png`, `bbc.png` — Logos dos bancos (adicionar antes do deploy)

## Deploy no GitHub Pages
1. Criar repositório no GitHub
2. Upload de todos os arquivos
3. Settings → Pages → Deploy from branch → main
4. Aguardar ~1 min e acessar `https://seu-usuario.github.io/am-financeira`
